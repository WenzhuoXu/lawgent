# Aviation overlay — /triage-nda

Layered when the aviation domain pack is active.

## Mandatory aviation carveouts (must be present or NDA → RED)

- **Regulator disclosure**: CAAC, MOT, FAA, EASA, NTSB, AAIB, BEA, BFU,
  DGCA, JCAB, ICAO state authority, TSA / 公安, customs, immigration.
  Bars on these carveouts are illegal or violate safety-disclosure duties.
- **Type-certificate / STC / DER data** — never barred from sharing with
  the issuing authority (FAA AIR / EASA CM / CAAC / 国家民用航空局适航司).
- **ASAP / FOQA / SMS** — disclosure to FAA / EASA / CAAC per Order
  8000.82, EU Reg. 376, CCAR-396 just-culture protections; NDA must not
  block these channels.
- **ITAR / EAR controlled technical data** — both parties acknowledge
  export-control posture; no transfer absent licence / exemption; deemed-
  export consideration for foreign-national personnel.

## Triage rules — additions

YELLOW triggers (aviation-specific):
- MRO / Part-145 capability data carveout missing.
- AOG-response data flow obligation absent.
- Insurance-broker disclosure carveout missing.
- Lessor / financier disclosure carveout missing where NDA touches
  aircraft data.

RED triggers (aviation-specific):
- Bar on safety-data disclosure to regulator (FAA / EASA / CAAC / NTSB).
- Bar on AD / SB compliance reporting.
- Demand for type-certificate / STC / proprietary OEM data without
  carveout.
- Demand to share CVR / FDR / QAR data outside Annex 13 limits.
- Demand for ITAR / EAR controlled technical data without export-control
  posture.

## Aviation-specific scope expectations

- 2–3 year term, 5 year survival baseline; trade-secret / type-certificate
  data may survive indefinitely.
- Permitted recipients explicitly include: insurers, brokers, regulators,
  outside aviation counsel, MRO providers, lessors, financiers.
- Residuals clause never applied to type-certificate data, STC data, or
  trade secrets.
