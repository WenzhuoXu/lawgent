# Aviation overlay — /vendor-check

Layered when the aviation domain pack is active.

## Aviation vendor types

- **MRO / Part-145** (heavy / line / component / engine).
- **Line-station** provider.
- **Parts supplier** (PMA / OEM-authorised / surplus / OEM distributor).
- **Lessor / financier / owner-trustee**.
- **OEM** (airframe / engine / component).
- **FBO** (US executive / Asia VIP).
- **Training** (Part-142 / Part-147 / EASA ATO / CAAC-approved).
- **IT / SaaS** vendor handling FOQA / ASAP / PNR / crew personal data.

## Aviation-specific diligence additions

- **Part-145 / Part-CAMO / AOC** certificate scope match for proposed
  services; capability list confirmed; capability list lapse / renewal
  date.
- **BASA / TIP** coverage for cross-border MRO / parts (FAA-EASA-CAAC
  bilaterals).
- **AOG response** SLA; spares pool access; loaner-engine availability.
- **PMA / OEM distributor** status; traceability process; ASA-100 /
  AS9120 quality cert.
- **FOQA / ASAP / SMS data MOU compatibility** — vendor must accept
  FAA Order 8000.82 / EU Reg. 376 / CCAR-396 protections; tri-party MOU
  template required.
- **Export-control posture** — ITAR / EAR posture; deemed-export risk for
  foreign-national personnel; denied-party screening.
- **Insurance** — aviation product / workmanship / MRO liability; war risk
  for hostile-environment stations.
- **Lessor / financier consent** — for any vendor change touching
  airworthiness / records / spares.

## Required agreement additions (aviation)

- MSA / SOW (services).
- AOG / line-maintenance agreement.
- Parts pool / loan agreement.
- Component / engine exchange agreement.
- IGTA (inter-airline ground / technical assistance).
- ASAP MOU / FOQA MOU (tri-party where applicable).
- Maintenance records transfer protocol.
- IDERA / DOR carveout for lessor vendors.

## Aviation-specific risk hooks

- AD compliance backlog at vendor.
- Recent FAA / EASA / CAAC enforcement findings against vendor.
- Loss of Part-145 capability listing in the proposed scope.
- Hostile-environment line-station risk profile (war risk, sanctions).
- SaaS vendor outside FOQA/ASAP data-localisation pathway.
