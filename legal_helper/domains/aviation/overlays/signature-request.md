# Aviation overlay — /signature-request

Layered when the aviation domain pack is active.

## Aviation transaction types

- Aircraft sale & purchase (cross-border + cross-registry).
- Operating lease delivery / redelivery.
- Sale-leaseback closing.
- Novation (assignment of leases / mortgages).
- MRO services agreement execution.
- Charter MOU / ACMI execution.
- AOC change / lessor consent execution.
- Engine / parts pool & exchange.

## Aviation closing-sequence additions

**Pre-closing**
- Title search at FAA Aircraft Registry (US) or applicable state registry.
- International Registry (Cape Town) priority search.
- Lien releases from outgoing financier / mortgagee.
- Bilateral export airworthiness approval (FAA Form 8130-4 / EASA Form 27 /
  CAAC equivalent).
- Insurance certificate(s) for hull / liability / war / cyber per playbook
  §1; AVN52E / AVN67B / LSW555D endorsements; severability / subrogation;
  cancellation notice clauses verified.
- IDERA in approved Cape Town form, signed by registered owner **and**
  operator; state-of-registry Article 13 declaration check.

**Closing**
- IDERA executed, dated, witnessed.
- DOR / DOR-EQ executed.
- Aircraft delivery certificate / acceptance certificate.
- Bill of sale (FAA AC Form 8050-2 for US registry; equivalents elsewhere).
- Lease / loan / mortgage execution.
- Engine acceptance certificates (LLP records, last shop visit).

**Filing**
- International Registry filings — international interest, sale,
  assignment, subordination, discharge; priority searches before + after.
- FAA AC Form 8050-1 (US registry application) + 8050-2 (bill of sale);
  state-of-registry equivalents (CAAC 民用航空器国籍登记证, EASA AOC + CofR
  application).
- Customs / VAT / import duties at destination.
- Insurance certificate amended for new registry.

**Post-closing**
- AD compliance summary delivery, CAMP entry, audit-rights calendar
  (playbook §4).
- Maintenance-records transfer in agreed form (playbook §5).
- Sub-lessee / wet-lease registration if applicable.
- ITAR / EAR posture confirmation for any controlled data flow.

## Aviation signatory checklist additions

For aircraft transactions the signatory matrix typically includes:

- Registered owner + beneficial owner (often distinct via owner-trustee).
- Operator (AOC holder), with capacity authentication.
- Mortgagee / security trustee.
- Hull + liability + war + cyber insurers (broker as agent).
- IR transactional user (entry-point + professional-user).
- State-of-registry regulator (where consent or non-objection is required).
- Engine + propeller owners if separately owned.
- Manufacturer / OEM for warranty assignment.
- Lessor + sub-lessor + sub-lessee where applicable.
