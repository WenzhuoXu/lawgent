# Aviation overlay — /meeting-briefing

Layered when the aviation domain pack is active.

## Counterparty types (aviation-specific)

- **Lessor / lessee** — operating, finance, sale-leaseback; ALC / AerCap /
  SMBC / BOC / CDB / ICBC; rated lessor list per playbook §9.
- **OEM** — Boeing / Airbus / Embraer / COMAC / Bombardier; engine OEMs
  (CFM / Pratt / RR / GE) and component OEMs (Honeywell / Collins / Liebherr).
- **MRO / Part-145** — heavy maintenance, line, component shop, engine MRO;
  CAAC / EASA / FAA Part-145 status.
- **Financier / trustee** — owner trustee, security trustee, mortgagee,
  ECA / EXIM Bank, ECGD.
- **Charter customer** — corporate, government, ACMI, wet-lease, broker.
- **Regulator** — CAAC / MOT / FAA / EASA / NTSB / DGCA / JCAB / DDTC /
  BIS / OFAC / TSA / customs / immigration.

## Aviation-specific issues to surface as Findings

- **Lease**: IDERA + DOR / DOR-EQ, return conditions, AD / SB threshold
  ($1M default per playbook §4), hull & liability minimums (playbook §1),
  Section 1110 protection, hell-or-high-water rent, novation procedure
  (playbook §9), sub-lease / wet-lease consent (playbook §10).
- **OEM**: TC / STC scope, ICA continuing-airworthiness, warranty + product-
  liability, parts pool, ITAR / EAR posture.
- **MRO**: capability list match, BASA / TIP coverage, AOG response SLA,
  liability cap (2× work-order value per playbook §6), insurance,
  export-control screening, audit rights.
- **Charter / ACMI**: AOC mismatch, cabotage, insurance writebacks, ground-
  stop routing, substituted-aircraft equivalence.
- **Regulator meeting**: scope of inspection / LOI / SD; privilege /
  ASAP / FOQA / SMS data posture; informal vs formal procedure.

## Aviation-specific governing-law preferences

Per playbook §8: NY law (US) or English law (international) for leasing;
Irish law for aircraft leasing; Singapore / Hong Kong for Asia-Pac;
sovereign-immunity waiver for state-owned operators.

## Aviation-specific escalation hooks

Per playbook §14: IDERA defect, § 1110 waiver, insurance below playbook
minima, uncapped AD threshold, AOC change without consent right, mandatory
safety-disclosure restriction in NDA, ITAR / EAR flow-down absent,
airworthiness / certificate / repossession impact.
