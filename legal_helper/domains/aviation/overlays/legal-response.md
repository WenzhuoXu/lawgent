# Aviation overlay — /legal-response

Layered when the aviation domain pack is active.

## Aviation authority types

- FAA: Letter of Investigation (LOI), Notice of Proposed Civil Penalty, EIR,
  Compliance Action; FAA Form 8000-13 informal procedures.
- NTSB: Request for Information (RFI), party-status letter, formal hearing
  notices.
- EASA: inspection findings, suspension/limitation notices, AOC oversight
  letters.
- ICAO state-of-operator / state-of-registry inquiries (Annex 13).
- TSA: Security Directive (SD) compliance response, IBP audit letter.
- BIS / DDTC / OFAC: directed disclosure, voluntary self-disclosure, denied-
  party advisory.
- CAAC: 行政处罚立案告知书, 监督检查记录, 适航指令执行情况查询.
- Border / immigration / police: cabin-incident report, passport-document
  preservation request.

## Onboard incident response standard (Tokyo / MP14 / Chicago Annex 9)

For passenger-handling incidents (passport destruction, unruly conduct,
immigration-document events, security escalation), surface bullets covering:

- factual triggers (quiet destruction, refusal to obey crew, evidence
  disposal, threat/violence, asylum claim, arrival without valid docs);
- crew/captain immediate authority (de-escalate, notify PIC, request
  voluntary preservation of fragments, secure fragments where lawful + safe,
  record names/seats/witnesses/timeline);
- notification (OCC, destination / alternate authorities, when
  inadmissibility / security handoff is likely);
- preservation (CCTV / crew reports / PNR / API / manifest, post-landing
  handover);
- limits (no immigration adjudication by crew, no punishment, limits on
  physical force / search / seizure / restraint / isolation / photography /
  data sharing absent safety / order / evidence justification + captain
  authority + local law).

Each bullet ends with one of: `treaty`, `regulation`, `ICAO`, `local-law`,
`best-practice`, `risk`, `drafting`.

## Aviation-specific privilege & disclosure

- ASAP / FOQA data: FAA Order 8000.82 / 14 CFR § 13.401; do not surrender
  beyond ASAP MOU carveouts.
- CVR / FDR: 49 USC § 1114; ICAO Annex 13 §5.12 — never disclose beyond
  investigation scope; insurer disclosure typically requires NTSB consent.
- SMS / occurrence reports: EU Reg. 376 just-culture protections; CAAC-equivalent
  protections for SDR / 民航安全自愿报告系统 data.
- Insurance: avoid admissions of liability in regulator filings; coordinate
  with insurer per policy notice clauses (hull / liability / D&O / cyber).
